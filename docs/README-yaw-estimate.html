Yaw Estimation: Mathematical Overview

This document explains how scripts/yaw_estimate.py and scripts/pose_math.py derive, from pure geometry, how many degrees the wrist must rotate about world Z to grasp an object in front of the robot.

This page documents the public grasp-axis geometry used by the demo.

1. What problem are we solving?

A parallel-jaw gripper closes along a linear axis. To grasp reliably we need:

  1. The object's horizontal projection on the table;
  2. The direction along which the fingers should close — for non-circular objects, usually the short side of the contour;
  3. The wrist yaw about world Z that aligns that axis with the gripper.

yaw_estimate.py handles (1)(2); pose_math.py handles (3).

Field to use: always read grip_yaw_deg for control and acceptance — not yaw_deg_estimated. The latter is mod 90° for backward compatibility only and loses the long-side vs short-side distinction for non-square objects.

2. From 3D point cloud to 2D contour

2.1 Table-plane filtering

The table is a plane:

$$\mathbf{n} \cdot \mathbf{p} = d$$

where $\mathbf{n}$ is the normal (plane["normal"]) and $d$ is plane["offset_m"]. Signed height for each point $\mathbf{p}_i$:

$$h_i = \mathbf{n} \cdot \mathbf{p}_i - d$$

Keep points near the object top height:

$$|h_i - h_{\text{top}}| \le \text{band}$$

(height_above_plane_m is $h_{\text{top}}$; default band_m = 0.005.)

Take world $(x, y)$ to form 2D top-face points $P = \{p_i \in \mathbb{R}^2\}$.

Geometric meaning: collapse the 3D object to a bird's-eye contour.

2.2 Convex hull

Noisy points are unstable for direct fitting. convex_hull_2d() uses the monotone chain algorithm to build hull $H$: the smallest convex polygon containing all points.

Turn orientation of three points $o, a, b$ uses the 2D cross product (twice the signed area):

$$\text{cross}(o,a,b) = (a_x - o_x)(b_y - o_y) - (a_y - o_y)(b_x - o_x)$$
  • $\text{cross} > 0$: left turn (CCW), keep;
  • $\text{cross} \le 0$: right turn or collinear, pop middle point.

The hull drops interior noise and keeps the outer boundary.

3. Core: minimum-area bounding rectangle (rotating calipers)

3.1 Why not PCA?

A square's covariance matrix is isotropic; the principal axis direction is noise, not object orientation. We use the minimum-area bounding rectangle (MABR), implemented by rotating_calipers_min_rect().

3.2 Key theorem

For a convex polygon $H$, the minimum-area enclosing rectangle has at least one side collinear with some hull edge.

(Intuition: if no side touches the hull, rotate toward the nearest hull edge without increasing area.)

So we need not search a continuous angle space — try each hull edge once (rotating calipers).

3.3 Per-edge computation

For hull edge $i$, edge vector $\mathbf{e} = p_{i+1} - p_i$, direction angle:

$$\theta = \operatorname{atan2}(e_y, e_x)$$

Rotate all hull vertices by $R(-\theta)$ so this edge aligns with the x-axis:

$$R(-\theta) = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix}$$
$$\tilde{p}_k = R(-\theta)\, p_k$$

Compute the axis-aligned bounding box (AABB) in the rotated frame:

$$\text{span}_x = \max_k \tilde{p}_{k,x} - \min_k \tilde{p}_{k,x}, \quad \text{span}_y = \max_k \tilde{p}_{k,y} - \min_k \tilde{p}_{k,y}$$
$$A(\theta) = \text{span}_x \cdot \text{span}_y$$

Pick $\theta^*$ that minimizes $A(\theta)$. Returns:

  • angle_rad = $\theta^*$
  • side_a_m: length along $\theta^*$
  • side_b_m: length perpendicular to $\theta^*$

4. From rectangle to gripper yaw

A parallel-jaw gripper closes along the short side:

  • Opening width = short side → grip_width_mm
  • Object length = long side → object_length_mm
$$\text{if } \text{side}_a \le \text{side}_b: \quad \phi_{\text{grip}} = \theta^*, \quad w = \text{side}_a, \quad L = \text{side}_b$$
$$\text{else}: \quad \phi_{\text{grip}} = \theta^* + \frac{\pi}{2}, \quad w = \text{side}_b, \quad L = \text{side}_a$$

Output angle (axis has no direction, mod 180°):

$$\text{grip\_yaw\_deg} = \deg(\phi_{\text{grip}}) \bmod 180^\circ$$

Why mod 180° and not mod 90°?

Legacy field yaw_deg_estimated = deg(θ*) mod 90° treats long and short sides as interchangeable. For an 80 mm × 30 mm rectangle, 10° and 100° map to the same mod-90 value, but the gripper axis differs by 90° (short vs long side). Since G009, grip_yaw_deg explicitly keeps the short-side direction.

5. Shape classification and symmetry

One geometric axis may have several equivalent orientations. Classification sets the period $T$ for wrap_to_symmetry().

5.1 Fill ratio

Shoelace formula (_polygon_area()) for hull area $A_H$; rectangle area $A_R = \text{side}_a \cdot \text{side}_b$:

$$\text{fill\_ratio} = \frac{A_H}{A_R}$$

Circle / ellipse$\pi/4 \approx 0.785$ (scale- and aspect-invariant)
Rectangle / square$1.0$

Threshold ROUND_FILL_RATIO_MAX = 0.89 sits midway with noise headroom.

5.2 Aspect ratio

$$\text{aspect\_ratio} = \frac{\max(\text{side}_a, \text{side}_b)}{\min(\text{side}_a, \text{side}_b)}$$

6. Applying to the robot wrist (pose_math.py)

6.1 Symmetry fold wrap_to_symmetry(yaw_deg, period_deg)

Fold to the minimum-rotation equivalent in $(-T/2,\, T/2]$:

$$r = \text{yaw} \bmod T$$
$$r \leftarrow \begin{cases} r - T & \text{if } r > T/2 \\ r & \text{otherwise} \end{cases}$$

Example ($T = 180^\circ$): 91° → −89° (shorter than rotating +91°).

Period must come from symmetry_period_deg — never hard-code 90°.

6.2 Quaternion composition quat_down_with_yaw(yaw_deg)

Base pose TARGET_QUAT_WXYZ points tool Z at world $-Z$ (downward). Additional rotation $\psi$ about world Z:

$$q_{\text{yaw}} = \left(\cos\frac{\psi}{2},\ 0,\ 0,\ \sin\frac{\psi}{2}\right) \quad \text{(wxyz order)}$$
$$q_{\text{target}} = q_{\text{yaw}} \otimes q_{\text{base}}$$

Left multiply (extrinsic / world frame) ensures:

  • The approach axis (tool Z → world $-Z$) stays fixed under world-Z rotation;
  • Horizontal gripper heading rotates by exactly $\psi$ in world frame.

7. End-to-end pipeline

flowchart TD
    A[Depth cloud + segmentation mask] --> B[Plane filter top-face points]
    B --> C[Project to XY]
    C --> D[2D convex hull]
    D --> E[Rotating calipers min-area rect]
    E --> F[Short side → grip_yaw_deg]
    E --> G[Shape class → symmetry_period_deg]
    F --> H[wrap_to_symmetry]
    G --> H
    H --> I[quat_down_with_yaw]
    I --> J[IK move to grasp pose]

Timing constraint: apply yaw only after capture finishes and grip_yaw_deg is measured — on the final grasp move. During capture the wrist must stay fixed; otherwise camera rotation corrupts pixel-offset geometry.

8. Worked examples

8.1 80 mm × 30 mm rectangle, long side 10° from world X

  1. Hull ≈ rectangle;
  2. MABR long side at 10°, short side at 100°;
  3. grip_yaw_deg ≈ 100° (fingers close along 30 mm short side);
  4. shape_class = elongated, symmetry_period_deg = 180;
  5. If current wrist yaw is 0°, wrap_to_symmetry(100°, 180) = 100° → rotate ~100° about Z.

8.2 50 mm square

Equal sides; MABR short/long interchangeable; 90° yaw ambiguity. shape_class = square_like, symmetry_period_deg = 90; fold to minimum rotation.

8.3 Circle

Min rectangle is a circumscribed square; orientation has no physical meaning. shape_class = round, symmetry_period_deg = None; control does not force yaw alignment.
