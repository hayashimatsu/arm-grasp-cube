Yaw 估計：數學原理說明

本文件說明 scripts/yaw_estimate.py 與 scripts/pose_math.py 如何用純幾何推導「面對眼前的物體，手腕要繞世界 Z 軸轉幾度才能夾起來」。

相關程式碼

模組職責
scripts/yaw_estimate.py從點雲估計物體頂面輪廓、最小面積矩形、夾爪軸方向
scripts/pose_math.py把估計角度折疊成最小旋轉量，合成朝下抓取姿態
scripts/capture_d455.py呼叫 region_yaw_estimate()，結果寫入 result.json
scripts/demo_api.py讀 grip_yaw_deg，經 wrap_to_symmetry → quat_down_with_yaw 交給 IK

本頁說明 demo 使用的公開抓取軸幾何計算。

1. 問題在數學上是什麼？

平行夾爪（parallel-jaw gripper）開合時，兩指沿一條直線軸靠近或離開。要穩定夾取，需要：

  1. 知道物體在水平桌面上的投影長什麼形狀；
  2. 找出手指應該沿哪個方向合攏——對非圓形物體，通常是輪廓的短邊方向；
  3. 把這個方向轉成機器人手腕繞世界 Z 軸要轉的角度。

yaw_estimate.py 負責 (1)(2)；pose_math.py 負責 (3)。

判讀欄位：控制與驗收一律看 grip_yaw_deg，不要看 yaw_deg_estimated。 後者只做 mod 90° 的向後相容，對非正方形物體會丟失「長邊還是短邊」的資訊。

2. 從 3D 點雲到 2D 輪廓

2.1 桌面平面過濾

桌面用平面方程表示：

$$\mathbf{n} \cdot \mathbf{p} = d$$

其中 $\mathbf{n}$ 是法向量（plane["normal"]），$d$ 是 plane["offset_m"]。 對每個點 $\mathbf{p}_i$ 計算有符號高度：

$$h_i = \mathbf{n} \cdot \mathbf{p}_i - d$$

只保留接近物體頂面高度的點：

$$|h_i - h_{\text{top}}| \le \text{band}$$

（height_above_plane_m 為 $h_{\text{top}}$，預設 band_m = 0.005。）

再取世界座標的前兩維 $(x, y)$，得到頂面在水平面上的 2D 點集 $P = \{p_i \in \mathbb{R}^2\}$。

幾何意義：把立體物體壓成鳥瞰圖上的輪廓點。

2.2 凸包（Convex Hull）

點雲有雜訊，直接用全部點擬合不穩。程式用 monotone chain 演算法 （convex_hull_2d()）計算凸包 $H$：包含所有點的最小凸多邊形。

判斷三點 $o, a, b$ 的轉向用的是 2D 叉積（有向面積的 2 倍）：

$$\text{cross}(o,a,b) = (a_x - o_x)(b_y - o_y) - (a_y - o_y)(b_x - o_x)$$
  • $\text{cross} > 0$：左轉（CCW），保留；
  • $\text{cross} \le 0$：右轉或共線，移除中間點。

凸包去掉內部雜點，保留外輪廓。

3. 核心：最小面積外接矩形（Rotating Calipers）

3.1 為什麼不用 PCA？

正方形的協方差矩陣是各向同性的，主成分方向是雜訊，不是物體真實朝向。 因此這裡用最小面積外接矩形（Minimum Area Bounding Rectangle, MABR）， 由 rotating_calipers_min_rect() 實作。

3.2 關鍵定理

對凸多邊形 $H$，面積最小的外接矩形，至少有一條邊與凸包的某一條邊共線。

（證明直覺：若矩形沒有任何邊貼齊 hull，可以朝最近的 hull 邊旋轉而不增大面積。）

因此不必搜尋連續角度空間，只要對凸包每條邊試一次即可——這就是 rotating calipers。

3.3 對每條邊的計算

設凸包第 $i$ 條邊向量為 $\mathbf{e} = p_{i+1} - p_i$，方向角：

$$\theta = \operatorname{atan2}(e_y, e_x)$$

把凸包所有頂點用旋轉矩陣 $R(-\theta)$ 轉到「這條邊與 x 軸平行」的座標系：

$$R(-\theta) = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix}$$
$$\tilde{p}_k = R(-\theta)\, p_k$$

在旋轉後座標系計算軸對齊包圍盒（AABB）：

$$\text{span}_x = \max_k \tilde{p}_{k,x} - \min_k \tilde{p}_{k,x}, \quad \text{span}_y = \max_k \tilde{p}_{k,y} - \min_k \tilde{p}_{k,y}$$
$$A(\theta) = \text{span}_x \cdot \text{span}_y$$

對所有 hull 邊取使 $A(\theta)$ 最小的 $\theta^*$，回傳：

  • angle_rad = $\theta^*$
  • side_a_m：沿 $\theta^*$ 方向的邊長
  • side_b_m：垂直方向的邊長

4. 從矩形到「夾爪 yaw」

平行夾爪應沿短邊合攏：

  • 開口寬度 = 短邊 → grip_width_mm
  • 物體長度 = 長邊 → object_length_mm
$$\text{若 } \text{side}_a \le \text{side}_b: \quad \phi_{\text{grip}} = \theta^*, \quad w = \text{side}_a, \quad L = \text{side}_b$$
$$\text{否則}: \quad \phi_{\text{grip}} = \theta^* + \frac{\pi}{2}, \quad w = \text{side}_b, \quad L = \text{side}_a$$

輸出角度（軸無方向性，mod 180°）：

$$\text{grip\_yaw\_deg} = \deg(\phi_{\text{grip}}) \bmod 180^\circ$$

為什麼 mod 180° 而不是 mod 90°？

舊欄位 yaw_deg_estimated = deg(θ*) mod 90° 假設長短邊可互換。 對 80 mm × 30 mm 長方形，轉 10° 與 100° 的 mod 90 值相同， 但夾爪軸其實相差 90°（一個沿短邊、一個沿長邊）。G009 起以 grip_yaw_deg 明確保留短邊方向。

5. 形狀分類與對稱性

同一個幾何軸可能有多個等價朝向。分類決定後續 wrap_to_symmetry() 用的週期 $T$。

5.1 填充率 fill_ratio

用 shoelace 公式（_polygon_area()）算凸包面積 $A_H$， 矩形面積 $A_R = \text{side}_a \cdot \text{side}_b$：

$$\text{fill\_ratio} = \frac{A_H}{A_R}$$
形狀理論 fill_ratio
圓／橢圓$\pi/4 \approx 0.785$（與尺度、長寬比無關）
矩形／正方形$1.0$

閾值 ROUND_FILL_RATIO_MAX = 0.89 介於兩者中點，留雜訊餘裕。

5.2 長寬比 aspect_ratio

$$\text{aspect\_ratio} = \frac{\max(\text{side}_a, \text{side}_b)}{\min(\text{side}_a, \text{side}_b)}$$
shape_class條件symmetry_period_deg意義
elongatedaspect > 1.2180°長條形，轉 180° 等價
roundfill_ratio < 0.89None圓形，朝向幾乎任意
square_like其餘90°正方形類，轉 90° 等價

6. 接到機器人手腕（pose_math.py）

6.1 對稱折疊 wrap_to_symmetry(yaw_deg, period_deg)

把角度折到最小旋轉量的等價代表角，區間 $(-T/2,\, T/2]$：

$$r = \text{yaw} \bmod T$$
$$r \leftarrow \begin{cases} r - T & \text{若 } r > T/2 \\ r & \text{否則} \end{cases}$$

範例（$T = 180^\circ$）：91° → −89°（比實際轉 91° 更短）。

週期必須從 symmetry_period_deg 讀入，不可寫死 90°。

6.2 四元數合成 quat_down_with_yaw(yaw_deg)

基準姿態 TARGET_QUAT_WXYZ 使工具 Z 軸指向世界 $-Z$（朝下）。 再繞世界 Z 軸轉 $\psi$ 度：

$$q_{\text{yaw}} = \left(\cos\frac{\psi}{2},\ 0,\ 0,\ \sin\frac{\psi}{2}\right) \quad \text{（wxyz 順序）}$$
$$q_{\text{target}} = q_{\text{yaw}} \otimes q_{\text{base}}$$

左乘（外旋、世界座標系）的用意：

  • 已朝下的接近軸（工具 Z → 世界 $-Z$）在繞世界 Z 旋轉下不變；
  • 水平面上的夾爪朝向旋轉恰好 $\psi$ 度。

7. 整體流程

flowchart TD
    A[深度點雲 + 分割 mask] --> B[平面過濾頂面點]
    B --> C[投影到 XY 平面]
    C --> D[2D 凸包]
    D --> E[Rotating Calipers 最小面積矩形]
    E --> F[取短邊方向 → grip_yaw_deg]
    E --> G[形狀分類 → symmetry_period_deg]
    F --> H[wrap_to_symmetry 折到最小角]
    G --> H
    H --> I[quat_down_with_yaw 合成手腕姿態]
    I --> J[IK 移動到抓取點]

時序限制：yaw 只能在 capture 完成、量測出 grip_yaw_deg 之後， 於最終 grasp 移動時套用；capture 期間手腕必須固定，否則相機朝向改變會污染像素偏移幾何。

8. 直覺範例

8.1 80 mm × 30 mm 長方形，長邊與世界 X 軸差 10°

  1. 凸包 ≈ 長方形；
  2. MABR 長邊沿 10°，短邊沿 100°；
  3. grip_yaw_deg ≈ 100°（手指沿 30 mm 短邊合攏）；
  4. shape_class = elongated，symmetry_period_deg = 180；
  5. 若目前手腕 yaw 為 0°，wrap_to_symmetry(100°, 180) = 100°，需繞 Z 轉約 100°。

8.2 50 mm 正方形

長短邊相等，MABR 的兩組邊可互換；yaw 有 90° 模糊。 shape_class = square_like，symmetry_period_deg = 90，折疊後取最小旋轉即可。

8.3 圓形

最小矩形為外接正方形，朝向無物理意義。 shape_class = round，symmetry_period_deg = None，控制端不強制對齊 yaw。

10. 數學工具一覽

數學工具用途
平面方程 + 高度帶3D → 2D 頂面投影
2D 叉積 / 凸包去雜訊、保留外輪廓
最小面積外接矩形 + rotating calipers找物體主軸與次軸（精確，非 PCA 近似）
短邊 = 夾爪開合軸平行夾爪幾何約束
fill_ratio / aspect_ratio形狀對稱與 yaw 模糊度
mod 180° / wrap_to_symmetry軸無方向性、取最小旋轉
四元數左乘（世界 Z）保持朝下，只改水平 yaw
一句話：用最小面積矩形包住物體頂面輪廓，把矩形短邊方向當成夾爪手指軸， 再依物體對稱性折成手腕該轉的最小角度。
